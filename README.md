# 🧲 MONEY MAGNET - BBRBET AGENT BOT 🎰

Este es un bot de Telegram profesional diseñado para la captación de afiliados y soporte automatizado para el casino **BBRBET**.

## 🚀 Funcionalidades
* **IA Agente:** Integración con DeepSeek para convencer a los usuarios de unirse.
* **Sistema de Referidos:** Rastreo de invitados y bonificaciones en MXN.
* **Keep-Alive:** Servidor Flask integrado para funcionamiento 24/7.
* **Generador de Imágenes:** Comando `/imagine` para marketing visual.

## 🛠️ Instalación
1. Clona el repositorio.
2. Instala las dependencias: `pip install -r requirements.txt`
3. Configura las variables de entorno:
    * `TELEGRAM_TOKEN`
    * `DEEPSEEK_KEY`
    * `ADMIN_ID`

## 💰 Monetización
Optimizado para el mercado de México con soporte para pagos en **MXN** y enlace directo de afiliado de BBRBET.
